# Project page sources (maintainer notes)

Static project page for *Repurposing Video Diffusion Transformers for Cross-View Temporal Object Correspondence* (GitHub Pages).

- `index.html` — the page (generated by `scripts/make_page.py`; edit the template there, not the HTML).
- `static/motivation/` — synchronized videos for the motivation figure (Ego-Exo4D "cutting board", Exo2Ego, 30 fps = 2x speed).
- `static/qual/{ego2exo,exo2ego}/` — XTrack qualitative results: `<take>_<object>_query.jpg` (query mask) + `<take>_<object>.mp4` (ego | exo prediction).
- `static/images/` — figures cropped from the paper. `static/paper.pdf` — the paper.
- `scripts/build_assets.py` — regenerates all videos/images from `/data3/_Nips26` (lab server only).

## Deploy
Push this directory to a GitHub repository and enable **Settings → Pages → Deploy from branch** (branch `main`, folder `/ (root)`).
