Abstract

Cross-view object correspondence identifies the same object across views. However, existing methods treat this as a frame-level matching problem, necessitating a query mask at every frame. Furthermore, without modeling temporal context, they suffer from severe ambiguity under appearance changes or occlusions. Therefore, we introduce cross-view temporal object correspondence, which requires preserving object identity across both views and time from a query mask. To address this, we propose XTrack, a streamlined framework which repurposes a pretrained video DiT with semantic and spatiotemporal priors for RGB-to-mask latent transport, jointly modeling cross-view matching and temporal tracking. However, naive video DiTs do not guarantee accurate cross-view grounding and often attend to semantically similar yet incorrect objects across views. Thus, we introduce focal cross-view attention alignment, hard negative conditioning, and local context crop strategies to ensure reliable grounding. Finally, beyond these architectural enhancements, we also tackle the lack of dense annotation by introducing a pseudo-label curation pipeline that converts sparse Ego-Exo4D annotations into dense supervision to enable effective video-level training. Our highly competitive performances validate the effectiveness of XTrack as a streamlined framework, ensuring robust temporal consistency and identity preservation.

Motivation: why joint view-time mask prediction?

Given a first-frame query mask in one view, the task is to recover temporally coherent masks of the same object in both views. Extending frame-level matchers with a tracker yields two decoupled pipelines, and both break under temporary disappearance and viewpoint change. XTrack predicts masks jointly across views and time within a single video DiT.

(a) Track-then-Match propagates the query mask in the query view and matches it per frame. (b) Match-then-Track estimates one initial match and tracks each view independently. (c) XTrack jointly models cross-view correspondence and temporal dynamics.

Method

Overall architecture. Ego and exo videos enter a pretrained video DiT as a diptych; the model transports RGB latents to mask latents for both views at once.
RGB → mask flow, not noise → RGB
  • Flow-matching endpoints redefined: source = RGB latent, target = mask latent.
  • The source already encodes scene layout, appearance and motion, so the DiT only has to convert evidence into masks.
  • Keeps the video DiT's spatiotemporal and semantic priors intact.
One token space for both views
  • Ego and exo frames are concatenated side by side; query mask conditions one side, the other side gets an empty mask.
  • Full 3D attention = within-view (tracking) + cross-view (matching) in every layer.
  • Ambiguity in one view is resolved with the other view, with no fixed initial match.
Focal attention alignment
  • Cross-view attention can drift to distractors.
  • Supervise target-side foreground tokens to attend to query-side foreground.
  • Focal weight: strong when grounding is weak, off when already correct.
Hard negative conditioning
  • Feed the wrong object's mask as a mismatched query.
  • Margin loss forces the two predictions apart.
  • Prediction depends on query identity, not on generic saliency.
Local context crop for small objects
  • Object-centred crop encoded as extra tokens next to the global ego-exo tokens.
  • RoPE positions copied from the crop's original coordinates, so local detail stays spatially aligned with the scene.
Two-stage training
  • Stage 1 — paired frames with a cycle-consistency loss: predict the other view, map back, must recover the query mask.
  • Stage 2 — video fine-tuning on dense curated pseudo-labels (below).
  • Inference: both views predicted jointly over time in a single pass.
